MANUAL JOB SEARCH TOOL
======================

Purpose
-------
This repository automatically collects recent security job postings
for manual application.

No AI is used.
No applications are submitted automatically.


SEARCH COVERAGE
---------------

Regions:
- Europe
- United Kingdom
- Canada
- Remote (Europe/UK/EMEA-friendly)

Job areas include:
- Application Security
- Product Security
- Security Engineering
- Cloud Security
- DevSecOps
- Software Security
- API Security
- Security Automation
- Platform Security / Security Platform
- Infrastructure Security
- Threat Modeling
- Vulnerability Management
- Security Research
- Security Architecture
- Staff / Principal / Lead paths

Platform Engineer roles are included only when the title clearly
relates to security / DevSecOps / cloud-security.


DATE FILTER
-----------

Only jobs posted within the latest 7 days are included.

The jobs_latest.xlsx file is replaced during each successful run.


VISA / SPONSORSHIP
------------------

The tool searches job-posting text for indicators such as:

- Visa sponsorship
- Visa support
- Work visa
- Work permit
- Relocation
- Immigration support
- Skilled Worker
- EU Blue Card
- LMIA
- Employer sponsorship

Possible values:

Yes / Mentioned
No
Not mentioned

IMPORTANT:

"Not mentioned" does NOT mean the company does not provide
visa sponsorship.

Always verify the company's actual requirements before applying.


EXCEL WORKBOOK
--------------

jobs_latest.xlsx contains:

- Posted Date
- Company
- Job Title
- Location
- Country
- Remote
- Visa/Sponsorship
- Salary
- Experience
- ATS
- Apply
- Status
- Job Description

The Apply column contains clickable links.
Existing Status values are preserved across refreshes.


WEBSITE (GitHub Pages)
----------------------

Source folder: /docs

Files:
  docs/index.html
  docs/styles.css
  docs/app.js
  docs/jobs_latest.json

The site shows job cards only (title, company, location, country,
remote, visa, posted date, APPLY, MARK APPLIED).

ABSOLUTELY NO job descriptions on the website.

APPLY opens the original apply URL in a new tab and does NOT mark
the job as applied.

MARK APPLIED stores the job in browser localStorage (New | Applied tabs).

JSON is generated by the scraper (no XLSX parsing in the browser).

AUTOMATION
----------

GitHub Actions runs the scraper automatically.

The workflow:

1. Starts a GitHub-hosted runner.
2. Installs Python.
3. Installs requirements.
4. Runs search_jobs.py.
5. Creates jobs_latest.xlsx and docs/jobs_latest.json.
6. Commits both files to this repository.

Trigger: daily schedule + workflow_dispatch.


MANUAL APPLICATION
------------------

The tool only provides a job list.

You manually:

1. Open the job (Excel or website APPLY).
2. Review the requirements.
3. Verify location and work authorization.
4. Review sponsorship information.
5. Apply on the employer's official application page.
6. Update Status (Excel) or MARK APPLIED (website).


DATA RETENTION
--------------

The workbook and JSON represent the latest 7-day search window.

Older job-list data is not intentionally accumulated.


IMPORTANT
---------

Job-search results depend on the underlying job sources and their
available data.

Always verify job availability, location, salary, sponsorship,
and application requirements on the original employer posting.
